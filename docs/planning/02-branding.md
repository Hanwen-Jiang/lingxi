# 品牌命名表 · 灵犀 Lingxi

> 2026-06-26 拍板:产品正式名 **灵犀(中文)/ Lingxi(英文 wordmark)**,取代旧产品名 InfiniteChat。本表是品牌使用的唯一出处。对应决策 `00-master-plan.md` D12。

## 1. 名字与含义

- **中文品牌:** 灵犀
- **英文 wordmark:** Lingxi
- **出处/故事:** 取自"心有灵犀一点通"——一种不必多言、近乎心电感应的默契。它**一词同时承载产品两层内核**:
  1. **AI 懂你**——助手有长期记忆 + 你的知识库(RAG),所以"秒懂"你的上下文;
  2. **人懂彼此**——它活在你和朋友/群的真实社交沟通里。
- **一句话定位:** 一个 AI 原生的社交沟通产品——懂你的,不只是消息。

**现在采用(用户可见层,低成本):**

| 范围 | 处理 |

**先不动(内部标识符,高 churn 低收益——留作内部代号,后续单独一次性重命名):**

| 范围 | 现状 | 说明 |
| --- | --- | --- |
| Java 包名 `com.lou.infinitechat*` | 保留 | 改名牵动全量 import/重构,价值低,留作代号 |
| Maven `artifactId`(如 `InfiniteChat-Agent`) | 保留 | 同上;CI/jar 名连带 |
| WSL 运行代号 `projecta-*` | 保留 | 部署脚本代号,与品牌解耦即可 |
| 目录命名约定(agent-backend / chat-backend …) | 按既定计划 | 与品牌无关,见各 RENAME 标记 |

> 规则:**"灵犀/Lingxi" = 对外品牌;"InfiniteChat" = 可继续存在的内部代号。** 二者并存不冲突;不要为了改名去动包名/artifactId,除非专门排一次"代号→品牌"重命名 pass。
